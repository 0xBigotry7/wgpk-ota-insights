## 已有文件的实证（不是泛指 OPERA 理论能力）

私有原件 `data/history-forecast-source.txt`，History & Forecast，55 列，149 个 A_STAT 实绩日期（3/1–7/27）、96 个 B_FORE 未来日期（7/28–10/31）；原件无明确导出时间、币种字段。原始数值和文件不进 Git。

### 本轮已实现

| 可以拿到的原始字段 | 本轮功能 | 边界 |
|---|---|---|
| NO_ROOMS、REVENUE、INVENTORY_ROOMS | 原有三指标／双月日历继续保留 | 原有重算及颜色用报表总库存；不是有效入住率 |
| CF_CALC_INV_ROOMS、CF_CALC_OCC_ROOMS、CF_OOO_ROOMS | 日期详情显示有效库存、OOO、有效入住率及有效 RevPAR；与原值逐项对账 | 不把“有效库存减入住计数”承诺成实际可售房；不重复扣 OOO |
| IND_DEDUCT_ROOMS/REVENUE、GRP_DEDUCT_ROOMS/REVENUE | 散客／团体扣库房量、收入、各自 ADR；房量及收入加总对账 | 不是 OTA 渠道、不是完整团体房块生命周期 |
| IND_NON_DEDUCT_ROOMS/REVENUE、GRP_NON_DEDUCT_ROOMS/REVENUE | 保存未扣库房量／收入，房量单列展示 | 不加到已售房量，不重复占库存 |
| ARRIVAL_ROOMS、DEPARTURE_ROOMS、NO_SHOW_ROOMS | 抵店／离店／no-show 原报表数量展示 | 未来 no-show 空值保持 null；不能得到取消率或订单级履约概率 |
| COMPLIMENTARY_ROOMS、HOUSE_USE_ROOMS、DAY_USE_ROOMS、NO_PERSONS | 免房／自用／日用／人数存储，前三者展示 | 不擅自再加减计数或推算净利润 |
| A_STAT 日期、房量、收入、总库存 | 独立预测基线及滚动回测（离线） | 不用 B_FORE 房量／收入、IDeaS 输出或未来实绩做特征；尚未生产发布 |

自动归档桥升级后会从原始归档补充 18 个数字字段；旧快照主表、来源日期、币种和收件日期不变。只有原件实际存在的字段才导入；旧报表没有的字段不补零。入退房同步和酒店 OPERA 配置均不改变。

实测所有 245 日期的四项对账均通过：总库存−OOO=有效库存；有效库存入住率=原报表入住率；散客+团体扣库房量=NO_ROOMS；两者收入=REVENUE。此结论只适用于本次样本，后续报表仍逐行检查，不能把字段名当永久口径保证。

## 独立预测第一次验证结果

实现 `python -m ota.forecast`，过去 56 天同星期的总库存入住率／RevPAR加权基线，并与不分星期的均值基线比较。训练只使用 as-of 前的 A_STAT，容量暂沿用末实绩总库存且明确标注假设。不是价格弹性模型，也没有声称学得 IDeaS 闭源算法。

逐日滚动起点，D+h 目标、训练严格早于 D，覆盖所有星期；不把重叠窗口当独立样本或置信区间。当前是探索性基线诊断，不是调参后的独立留出验收。

| 提前天数 | 回测配对数 | 星期基线入住率 MAE（百分点） | 不分星期基线 MAE |
|---|---:|---:|---:|
| 1 | 92 | 13.22 | 12.34 |
| 7 | 86 | 14.95 | 13.46 |
| 14 | 79 | 16.13 | 14.50 |
| 30 | 63 | 16.74 | 16.33 |

房量 WAPE 约80–96%、收入 WAPE 约131–155%（星期基线），偏差明显偏高。短样本、趋势变化、停用房变化是待分析因素，不能凭本轮指标把根因归为某一项。**尚不具备上线条件**；保留可执行基线与完整私有回测结果，不把不合格预测染色成正式未来日历。旧样本的 90 天预测仍是 7/28 时点的离线推演，不是今天／11月实时预测。

## 下次 OPERA 再核验（不阻塞上面的实现）

1. 新的同款 History & Forecast：确认业务日、币种／税费／容量字段，恢复持续经营报告；已有接收桥可自动解析。
2. 更长历史：尽量覆盖完整旺淡季和去年同期；不要为等待两年历史停止当前工作。
3. 未来预订、逐晚房费、创建／修改／取消时间、状态；用于 pickup、提前期、取消模型。已有入住和明确退房不能代替这些事件。
4. 团体房块：逐日扣库／未扣库、已转订单、cutoff、状态变化，防止重复计算。当前报告只有聚合拆分，不等于完整 block 数据。
5. 房型／市场／来源／渠道映射及成本：已有公司／代理／RATE_CODE 字段不自动等于全渠道收入或净佣金。
6. 历史 as-of 快照：未来从现有接收桥累积；单次旧报表不能反推过去各日的订房进度。

不要求先开 OHIP；报表能导出就先沿用报表。竞品／外部活动单独找独立来源，不能从 OPERA 报表虚构。
